# 数据准备与实验方法

下列路径均相对于项目根目录。`data/` 用于存放本地数据，`outputs/` 用于保存运行结果。

## 银行贷款审批

### 数据

将 `bank_train.csv` 和 `bank_test.csv` 放在 `data/bank/`，或用 `--data-dir` 指向已有目录。CSV 采用 UTF-8 编码并包含表头。

| 字段 | 含义 | 格式 |
| --- | --- | --- |
| `profession`、`education` | 职业、教育类别 | 整数编码 |
| `house_loan`、`car_loan`、`married`、`child` | 是否有房贷、车贷、已婚、育有子女 | 整数编码 |
| `revenue` | 收入 | 数值 |
| `approve` | 审批结果 | `0` 为拒绝，`1` 为批准 |

如果文件包含 `nameid` 样本编号，读取时会略过该列。`--demo` 生成相同结构的合成数据，可用于检查模型训练和评估流程。

### 模型与评估

1. 从训练文件分层抽取 20% 作为验证集。scikit-learn 树比较 Gini 和信息熵以及三组深度、最少分裂样本数、最少叶样本数组合。它直接使用 `revenue` 找候选阈值。
2. 手写 ID3 将收入按 10,000、15,000、20,000、28,000、40,000 分为六档，阈值落在较低一档。在每个节点选信息增益最大的特征，按取值建多个子节点。信息增益等于当前标签熵减去划分后按样本数加权的条件熵。如果预测样本的类别值在当前节点未出现，则返回该节点的多数类。
3. 用验证集的正类 F1 选择各树的参数。ID3 在最大深度 3、5、10 和不限深度之间选择，平分时优先选浅树。两种树用完整训练文件重训，在测试文件上汇报准确率、精确率、召回率和 F1。额外评估一个不限深度的 ID3，用于观察剪枝影响。

测试结果包含三组混淆矩阵和 scikit-learn 树的结构图。两种树收到同一组字段，其中类别字段以整数表示。scikit-learn 按数值顺序做二元阈值划分，ID3 按类别取值做多路划分，两者对离散列的处理也会影响结果。

## 手写数字识别

### 数据与基线

[torchvision MNIST](https://docs.pytorch.org/vision/main/generated/torchvision.datasets.MNIST.html) 的 60,000 张训练图按固定随机种子划成 50,000 训练和 10,000 验证，官方 10,000 张测试图保留为测试集。28×28 灰度图先缩放到 0–1，再用均值 `0.1307`、标准差 `0.3081` 标准化。`--demo` 使用 [scikit-learn digits](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html) 并重新划分训练、验证、测试集。

基线为 `Flatten → Linear(784, 128) → ReLU → Linear(128, 10)`，使用 Adam（学习率 `0.001`）、交叉熵、批量大小 64、训练 5 轮。输出层是 logits，可直接送入交叉熵。

### 单变量比较与扩展

| 方向 | 配置 |
| --- | --- |
| 批量大小 | 32、64、128 |
| 隐藏层数 | 1、3、5，每层宽 128 |
| 隐藏层宽度 | 64、128、256、512 |
| 激活函数 | ReLU、Sigmoid、Tanh、LeakyReLU |
| Dropout | 0、0.2、0.5，放在隐藏层激活后 |
| 联合调参 | 批量 32 + 宽度 256，或宽度 256 + Dropout 0.2 |
| 训练集增强 | 在基线 MLP 的训练批次随机旋转至 ±10°、沿两轴平移至 ±2 像素 |
| 小型 CNN | 两组卷积、BatchNorm、ReLU 和最大池化，最后接全连接输出层 |

每组从同一个随机种子开始并使用相同的数据划分。数据增强发生在标准化之前，验证集和测试集只做标准化。训练阶段累计每轮的批次损失和正确率，验证时关闭 Dropout 并固定 BatchNorm 的运行统计。最终轮的验证准确率决定本次运行选用哪个配置，随后在测试集上评估该模型，记录交叉熵、准确率、宏平均 Precision、Recall 和 F1。

## 中文新闻标题分类

### 数据

使用本地的 `data/news/train.txt`、`dev.txt`、`test.txt`。文件为 UTF-8，每个非空行的格式是 `标题<TAB>类别`，`\t` 为真实的制表符。同目录可选放置 `stopwords.txt`，每行一个停用词。实验使用的标题子集来自 [THUCNews](https://github.com/thunlp/THUCTC#中文文本分类数据集thucnews)，完整语料与这里的三份标题划分需要分别准备。可运行 `--demo` 使用项目生成的四类标题。

### 特征与评估

1. 统计样本数、类别数与标题长度。用 jieba 分词，统一英文大小写，提取汉字、英文和数字片段并过滤停用词。
2. 用训练集拟合词频矩阵，保留文档频率至少为 2 的特征，词表上限为 10,000。验证与测试集复用训练词表。
3. 验证集比较 unigram 与 unigram + bigram，结合七个 `alpha` 值（`0.01`、`0.05`、`0.1`、`0.5`、`1`、`2`、`10`）。用 Macro-F1 选最佳配置。Macro-F1 对每类 F1 等权平均，能看到少数类效果。
4. 手写多项式朴素贝叶斯在稀疏矩阵上按类别统计词频。每个词频加上 `alpha` 后归一化，预测时将词频向量与各类的条件对数概率点乘，再加上对数类别先验。固定 unigram 与 `alpha=1`，逐条核对验证和测试预测与 scikit-learn 的一致性。
5. 用同一份测试集比较调好的词袋模型、在相同词表与 `alpha` 上使用 TF-IDF 的模型，以及 unigram 词袋上的 LinearSVC。重点关注准确率、Macro-F1 和 Weighted-F1。

混淆矩阵以 `metrics.json` 中 `label_order` 的零基索引标注类别。`frequent_confusions` 列出最常见的误判方向和计数，可结合每类召回率定位容易混淆的类别。
